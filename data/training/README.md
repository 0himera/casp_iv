обучен на той же популяции и сравнен на прежнем сентябрьском периоде.

Проверено 12.11.2026: найдены и скачаны данные с фактическими событиями контейнерной
обработки. Для первого обучаемого компонента выбран **Event Log Dwelling Time Dataset**.
Это основание для эксперимента с длительностью обработки в терминале. Проверку качества
на Каспии этот набор не заменяет: название и местоположение терминала анонимизированы.

Обучение выполнено: [результаты, веса и API](../../models/terminal-dwell/v1/README.md).
При обучении выявлен неоднозначный масштаб GROSS в 18 022 случаях; они дополнительно
исключены без догадок о переводе единиц. Исходная таблица из 95 587 примеров сохранена
для аудита; финальная модель обучалась на временной подвыборке с допустимым масштабом массы.

## Основной набор: события контейнерного терминала

- Источник: [Mendeley, версия 2](https://data.mendeley.com/datasets/yvp2b4rtp3/2),
  DOI [10.17632/yvp2b4rtp3.2](https://doi.org/10.17632/yvp2b4rtp3.2).
- Авторы: Hanung Nindito Prasetyo, Riyanarto Sarno, Kelly Rossa Sungkono, Indra Waspada,
  Raden Budiraharjo. Лицензия датасета: **CC BY 4.0**.
- [Статья авторов](https://pmc.ncbi.nlm.nih.gov/articles/PMC11424786/) описывает
  происхождение записей из операционной системы и анонимизацию.
- Полный XLSX скачан без входа и ключа: 63 774 563 байта. SHA-256 совпал с хешем
  издателя: `fd4ddc8e50f57cceb84881461f85a142137785ca81f59b37165ae484412f7d8c`.
- Полным чтением подтверждено **952 069 событий и 95 648 отдельных случаев**.
  Есть BAPLIE, VESSEL_ATB, DISCHARGE, CUSTOMS_DEL, JOB_DEL, TRUCK_OUT и дополнительные
  таможенные/карантинные действия. Один вариант названия TRUCK_IN содержит лишний пробел.

Извлечена таблица для первой задачи: **сколько часов после завершения выгрузки остаётся
до выезда контейнера на автомобиле**. Момент прогноза — конец DISCHARGE; результат —
конец TRUCK_OUT. Это обработка входящего контейнера, а не готовность к исходящему парому.

После базовой очистки осталось **95 587 примеров**, исключён 61 случай с проблемными
timestamp. Обнаружены 54 отсутствующих времени начала, шесть событий CUSTOMS_DEL с
датой 1954 года и одно с датой 2022 года при заявленном сборе в 2021 году. Даты не
исправлялись догадками: соответствующие случаи исключены целиком. Это консервативное
правило очистки; оно может создавать смещение выборки.

Входы таблицы: размер/тип контейнера, масса, час, день недели и месяц. Размер/тип/масса
берутся только из событий, завершившихся к моменту прогноза. Будущие действия таможни,
конец TRUCK_OUT, итоговая длительность и идентификатор случая не должны попадать в X.
Медианная целевая длительность — около **53,5 часа**, P90 — около **171,5 часа**.
Это описательные характеристики выборки, не метрики качества модели.

Готовая локальная таблица: `backend/var/training/container-dwell.csv`.
Исходный XLSX: `backend/var/dataset-search/container-dwell.xlsx`.
Оба больших файла исключены из Git. [Полный профиль и хеш таблицы](mendeley-profile.json)
и [каталог источников](sources.json) хранятся в репозитории.

Для первого эксперимента: CatBoostRegressor по времени до выезда, затем квантильные
P10/P50/P90. Сравнить с медианой обучающей выборки и медианой по типу/размеру контейнера.
Разделять данные по времени и целым случаям. При обучении на историческую дату включать
лишь те исходы, которые уже завершились к этой дате. Контролировать MAE в часах,
квантильную ошибку и покрытие интервалов. Метрики первого эксперимента
опубликованы в карточке модели по ссылке выше. Классификатор
пропуска cutoff на этих записях не обучался: исходящих cutoff в наборе нет.

Ограничения: timezone и recorded_at источником не предоставлены. Время завершения
события используется как приближение момента доступности атрибутов. Нет геопривязки
для погодного join, подтверждённых мест на пароме, исходящих cutoff и маршрута всего
груза. Каспийскую погоду к этим записям присоединять нельзя.

## Воспроизведение

Из `backend/`:

```bash
# Скачивание без API-ключа с проверкой размера и SHA-256.
uv run python -m scripts.fetch_training_source mendeley

# Потоковое чтение XLSX, очистка и извлечение временной цели.
uv run --with openpyxl --with lxml python -m scripts.inspect_training_data \
  --xlsx var/dataset-search/container-dwell.xlsx \
  --output var/training/container-dwell.csv \
  --profile ../data/training/mendeley-profile.json

# При необходимости скачать проверенный архив другого набора:
uv run python -m scripts.fetch_training_source caribbean
```

Все ссылки, проверенные размеры/хеши и ограничения перечислены в sources.json.
`frontend/`, API прогнозов и веса моделей в этой задаче не менялись.
