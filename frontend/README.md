# Caspian Transit frontend

Next.js + React + TanStack Query. Прототип кейса Smart Caspian Transit.

```bash
bun install --frozen-lockfile
CASPIAN_API_URL=http://127.0.0.1:8000/api/v1 bun run dev
```

Браузер обращается к `/api/backend`, Next.js проксирует запросы в FastAPI.
Сервис backend и постоянный Casper-worker запускаются отдельно: см.
`../backend/README.md` и `../docs/TRANSIT_API.md`. Mock на 4010 для основного потока не нужен.

## Источник состояния

- Карточка, маршруты, риски, ETA, ESG и паспорт приходят с backend.
- «Пересчитать прогноз» и сценарии вызывают `/shipments/{id}/recalculate`.
  Панель условий показывает допущения и происхождение наблюдений.
- При смене роли действия ждут загрузки свежей ревизии карточки.
- Выбор маршрута, загрузка документа и решение роли создают Operation.
  `queued/submitted` не меняют согласованный паспорт локально. После `confirmed`
  карточка перечитывается; при `failed` остаётся прежнее состояние и показывается ошибка.
- Таможенная роль имитируется. Нет кнопки, подписывающей все роли сразу.
- Весь грузовой сценарий демонстрационный. Открытые погодные/портовые данные
  не превращают его в фактическое отслеживание груза оператора.

Preview-токены ролей опубликованы по решению команды для хакатона. Это не схема
доступа для промышленного сервиса. Локальные signing keys остаются только у worker.

```bash
bun test
bun run lint
bun run build
```

Сквозной сценарий: `../docs/NEXT_STEPS.md`. Архитектура и ограничения:
`../docs/ARCHITECTURE.md`. Генерируемые DTO: `../api/public-data.types.ts`.

## Рабочее пространство карты

Главная страница — рабочее поле на `100dvh`, без лендинга и прокрутки всей страницы.
За основу взаимодействия взята карта до bento-редизайна (`981f490`).
Плавающая панель из матового стекла объединяет маршруты, прогноз, документы и порты.
В раскрытом виде её ширина 380–480 px, иконки находятся в верхней строке.
При сворачивании сохраняется окно 96×212 px (примерно 1:2.2) у того же правого края:
иконки переходят в вертикальный ряд. Окно и те же кнопки анимируются за 420 мс,
при `prefers-reduced-motion` переход мгновенный. Скрытое содержимое `inert`;
фокус возвращается на активную иконку. Черновики, поиск и прокрутка не размонтируются.
Карта продолжается под окном; камера учитывает его открытую и компактную формы.
На телефоне окно закреплено снизу справа. Левой и нижней дублирующей навигации нет.

Отправка и preview-роль выбираются в шапке. Прогноз содержит погоду, условия
расчёта, транспортную цепочку и дополнительные симуляторы. Документы содержат
подтверждённую проекцию Casper и действия текущей роли. X-ray и дублирующие меню
удалены из основного потока. Hero-иллюстрация сохранена как ресурс, но не загружается.

Карта подбирает обзор под доступное место и положение груза. При ручном
масштабировании перестаёт сбрасывать камеру на изменение размера. «Весь Каспий»
возвращает общий обзор. Поиск опубликованных связей включает слой и выделяет
найденную геометрию, не меняя выбранный маршрут груза.

### Фактура воды

«Слои → Текстура воды» включает GLSL Bayer-дизеринг в контексте MapLibre.
Рисунок ограничен маской воды с островами и расположен под маршрутами и подписями.
Темизация базовых тайлов не меняет собственные GeoJSON-слои воды, погоды и путей.
Движение ограничено 10 кадрами/с и приостанавливается в скрытой вкладке.
Для `prefers-reduced-motion` и сенсорного указателя фактура статична. Ошибка эффекта
оставляет базовую карту; GPU-ресурсы освобождаются при выключении и смене режима.

## Проверка интерфейса

Проверены 27 тестов frontend, ESLint, production build и браузерные сценарии:
1280×900, 2560×1440 и мобильные ширины 320/390 px; переключение панелей, карта/граф, поиск портов,
инспекторы, слои, выделение связей, сворачивание панели, роль и отправка.
Реальный backend проверен через скачивание подтверждённого документа с SHA-256,
чтение архивной версии v1, экспорт доказательства и сверку хешей с Casper testnet.
Отзыв и ошибки проверены с перехваченными ответами API в браузере, а также backend
и Odra-тестами; живые подписи для проверки интерфейса не отправлялись.

## Документы и контракт

- Скачивание берёт байты подтверждённой версии с авторизацией роли и проверяет SHA-256.
- Архив показывает сохранённые снимки, версии документов и журнал событий; снимок
  с commitment proof можно экспортировать в JSON. Архив не обозначается как текущий статус.
- «Сверить с блокчейном» читает `/passport-state` по запросу, показывает блок/время,
  сопоставляет версию и два хеша. RPC-ошибка не отображается как успешная проверка.
- Отозвать можно только своё активное approval текущей версии. Есть отдельное
  подтверждение с предупреждением об окончательности решения в этой версии.
  До `confirmed` локальные подписи не меняются. Повторный `attest` не предлагается.
- `Operation`, `Health`, состояние сети и архивные ответы берутся из генерируемых
  типов `api/public-data.types.ts`. Детальная карточка обновляется раз в 30 секунд
  только в активной вкладке; прямое чтение Casper не опрашивается автоматически.
В старом автономном `tools/mock-api.test.mjs` отдельно воспроизводится существующая
ошибка проверки устаревшего forecast: mock отвечает 202 вместо ожидаемого 409.
Этот mock не используется рабочим интерфейсом; его код в изменении темы не затрагивался.

### Темы интерфейса

Светлая палитра — холодный голубой и матовое полупрозрачное стекло. Тёмная — синие поверхности с отдельными контрастными цветами карты, маршрутов и статусов. Переключатель солнце/луна находится в шапке. Первый визит следует системной теме; ручной выбор сохраняется в `localStorage` (`caspian-theme`) и синхронизируется между вкладками. Ранний скрипт в layout применяет тему до первого кадра. Переключение не пересоздаёт карту и не сбрасывает открытую панель, поиск или положение камеры.

Палитры и стеклянные поверхности: `src/app/styles/tokens.css`. Компоненты используют семантические CSS-переменные; WebGL-слои обновляют разрешённые цвета при смене темы.
